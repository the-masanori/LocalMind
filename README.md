# LocalMind

外部通信なしで動く、単体HTML/JSのマインドマップツールです。

## 起動

`index.html` をブラウザで開きます。サーバーは不要です。

## 保存と再開

右側のMarkdownをコピーして保存し、再開時は貼り付けて「反映」を押します。入力内容は同じブラウザのローカル保存にも残ります。

## Markdown形式

```markdown
# 中心トピック
> 中心トピックのコメント
- 子トピック
  > 子トピックのコメント
  - 孫トピック
    > 孫トピックのコメント
- 別の子トピック
```

## 主なキー操作

- 伸び方: 画面上部の `左右` / `右方向` で切り替え
- 表示: 画面上部の `通常` / `番号` で切り替え
- `Ctrl + Z` / `Command + Z`: 元に戻す
- `Ctrl + Y` / `Command + Shift + Z`: やり直す
- `F2` / ダブルクリック: ノード名を編集
- `Enter`: 選択ノード名を編集
- 編集中の `Shift + Enter`: ノード内で改行し、2行目以降をコメントとして表示
- `Space`: 選択ノードを折りたたみ/展開
- ノード右上の `+` / `−`: そのノードを折りたたみ/展開
- `Ctrl + Enter` / `Command + Enter`: キャンバス上で同階層に追加
- キャンバス上の `Shift + Enter`: 子ノードを追加
- `Tab`: 子ノードを追加
- `Option + Tab`: 選択ノードを一段下げる
- `Shift + Tab`: 選択ノードを一段上げる
- ノードをドラッグ: 枝ごと表示位置を調整
- 全体表示ボタン: 手動配置をリセットして全体表示
- `Option` / `Alt` + ノードを別ノードへドラッグ: 親ノードを付け替え
- `Delete` / `Backspace`: 削除
- `Arrow`: 選択移動
- `Command + ArrowUp/Down`: 並び替え
- `Command + C`: Markdownをコピー
- `Command + M`: Markdown欄へ移動
- `Command + Enter`: Markdown欄で内容を反映

日本語入力中はショートカットを処理しないようにしています。
